## Listing description

Your T3 Code workspace has a campus now. T3Craft connects directly to your paired T3 Code machines: chats, workspaces, approvals and execution stay owned by T3 Code. Walk the floor, find the conversation, and see what needs your attention.

### Credits and origins

This project is a fork of [AgentCraft by blendi-remade](https://github.com/blendi-remade/agentcraft), which supplies the original Minecraft studio, HQ, blocks and presentation. The paired Java client is adapted from [t3craft by Maxwell Young](https://github.com/maxwellyoung/t3craft). Both projects are MIT licensed; their attribution and licenses are retained.

[T3 Code by the T3 Tools team](https://github.com/pingdotgg/t3code) supplies the actual conversations, providers, workspaces and AI execution. This community Minecraft integration also adapts T3 Code's MIT-licensed theme palettes. It is not an official T3 Code release.

Resident skins come from [Minetest Skins Pack 1 by isaiah658](https://opengameart.org/content/minetest-skins-pack-1), released under CC0. See the [complete third-party notices](https://github.com/70869/t3craft/blob/main/THIRD-PARTY-NOTICES.md).

Chat through a compact workspace sidebar. See which thread each resident represents; catch work states through color, motion and a typing burst. All eighteen resident work assignments stay on the main floor. When the work is done, residents head for the lounge: snacks, phones, a stretch, a little room to breathe.

The pack includes the author's latest cleaned campus snapshot: buildings, terrain, signs and physical stations, with private player data and account configuration removed. Every fresh install starts with this world.

### Getting started

1. Install this pack in Modrinth App or import its `.mrpack` in Prism Launcher.
2. Use Java 25+ and a Minecraft account that owns Java Edition.
3. Start [T3 Code](https://github.com/pingdotgg/t3code) separately.
4. Open **AgentCraft HQ** from Minecraft's Singleplayer menu.
5. Pair privately through **Connections**, using a fresh link from T3 Code's Settings → Connections.

T3 Code supplies the actual provider connections and execution. Opening Minecraft or selecting a thread does not start a run. The pack contains no credentials, pairing links or private chat history.

Back up your world before a launcher-managed pack upgrade. The [GitHub Windows installer](https://github.com/70869/t3craft/releases/latest) supports verified backups and preserves existing Prism saves while updating the managed mods.

Windows gameplay and synthetic paired-client protocols 1/2 have been checked. Native macOS/Linux gameplay and additional shader combinations have not been verified.
